# Проверка стартового комплекта

Комплект проверен до передачи студенту:

- Python 3.12; MLflow 3.5.0; scikit-learn 1.7.2.
- `pytest -q`: 14 тестов прошли. Проверены предсказания экспортированного
  Pipeline, валидация API, NaN/Infinity, повреждение файла модели и отсутствие
  одинаковых векторов признаков в разных частях выборки.
- `pip check`: конфликтов зависимостей нет.
- Все 139 пакетов полного lock-файла скачаны как готовые wheels для
  Linux ARM64 / Python 3.12 (включая универсальные pure-Python wheels).
  Их платформенные теги дополнительно сверены с glibc 2.35 Ubuntu 22.04 ARM64.
- Проверен отдельный bootstrap через `uv==0.13.5`: установка CPython 3.12.14
  в частный каталог и создание `.venv` с pip без замены системного Python.
  ARM64 wheel uv и запись Linux ARM64 в каталоге CPython 3.12.14 проверены.
- В изолированной тестовой копии выполнены шесть MLflow-запусков, две версии
  Registry, экспорт, две сборки Docker, API-проверки, обновление и откат
  с тем же ID исходного образа, Compose и healthcheck. Сборщик сохранил результаты
  и остановленный MLflow; отсутствие скриншотов корректно помечено как false.
- Окончательный API дополнительно проверен в пересобранном контейнере:
  корректный запрос, совпадение предсказаний, восемь ошибочных запросов.

**Это проверки инфраструктуры на синтетической фикстуре в Debian/x86_64,
а не эксперименты CCPP на Ubuntu ARM64.** Фикстура и её измерения не включены
в стартовый архив и не могут быть использованы как результаты лабораторной.
В облачной среде загрузка с UCI получила HTTP 403; поэтому реальные данные
скачиваются скриптом на машине студента или вручную с официальной страницы.

Запуск на вашей Ubuntu ARM64 и реальные метрики CCPP ещё предстоит получить.
Сохранённые вами данные в reports/ и скриншоты станут основанием отчёта.
